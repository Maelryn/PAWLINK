# PawLink

Animal rescue, care and adoption platform for Algeria.

| Folder | What |
|---|---|
| `web/` | Next.js website (see `web/README.md`) |
| `brand/` | Logo (PNG + SVG, light & dark) |
| `docs/` | `FRONTEND_PLAN.md`, `BRAND_AND_ASSETS.md` (AI prompts), **`TEAM_HANDOFF.md` (who does what)** |

```bash
cd web
npm install
npm run dev
```

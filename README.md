# PawLink

Animal rescue, care and adoption platform for Algeria.

| Folder | What |
|---|---|
| `apps/web/` | Next.js website (see `web/README.md`) |
| `apps/mobile/` | Expo SDK 57 + React Native app (see `docs/MOBILE_PLAN.md`) |
| `apps/backend/` | NestJS backend — empty for now |
| `apps/Ai/` | AI service — empty for now |
| `brand/` | Logo (PNG + SVG, light & dark) |
| `docs/` | `FRONTEND_PLAN.md`, `MOBILE_PLAN.md`, `BRAND_AND_ASSETS.md` (AI prompts), **`TEAM_HANDOFF.md` (who does what)** |

```bash
cd apps/web
npm install
npm run dev
```
